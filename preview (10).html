DJ Gloggi • The Gustx Broadcast

Privacy Policy

Effective and last updated: September 10, 2026

DJ Gloggi ("DJ Gloggi," "the app," "we," or "our") is a livestream utility used with Streamer.bot for The Gustx Broadcast. It lets livestream viewers submit YouTube video links through chat, validates those requests, adds accepted videos to a designated YouTube playlist controlled by the authenticated channel owner, and displays the current request and queue in an on-stream DJ overlay.

This policy explains what information DJ Gloggi accesses, how that information is used, where it is stored, when it is deleted, and the choices available to users.

1. Google and YouTube user data DJ Gloggi accesses

DJ Gloggi uses OAuth 2.0 and the YouTube Data API v3. The app requests the Google OAuth scope https://www.googleapis.com/auth/youtube.force-ssl. Google classifies this as a sensitive scope. The scope is used because YouTube requires an authorized YouTube scope to insert a video into a playlist.

Although Google's user-facing description for this scope is broad, DJ Gloggi's implementation uses that authorization only for the limited functions described below.

Google/YouTube data or authorizationHow DJ Gloggi uses it
OAuth access tokenAuthenticates authorized requests from Streamer.bot to the YouTube Data API.
OAuth refresh tokenObtains a replacement access token after the short-lived access token expires, so the channel owner does not need to sign in before each playlist request.
Designated YouTube playlist IDIdentifies the playlist selected by the channel owner as the destination for accepted DJ requests.
YouTube video ID and video metadataDJ Gloggi checks the submitted video and reads the video's title, channel name, thumbnail, duration, live-status information, and embed availability so it can validate the request and display it in the overlay.
Playlist write authorizationAfter a request passes the app's validation rules, DJ Gloggi uses YouTube's playlist API to add that video to the designated playlist.

Google data DJ Gloggi does not intentionally access or use

DJ Gloggi does not use the granted authorization to read or manage the authenticated user's Gmail, Google Drive, Contacts, Calendar, Google Account password, YouTube watch history, subscriptions, comments, ratings, captions, uploads, or unrelated playlists. It does not upload videos, edit video metadata, delete videos, manage comments, or manage subscriptions.

Livestream viewers do not authenticate a Google account with DJ Gloggi. A viewer submits a YouTube link through livestream chat; the Google OAuth authorization belongs to the broadcaster/channel owner operating DJ Gloggi.

2. Livestream chat and song-request data

When a viewer uses the DJ request command, DJ Gloggi may process and temporarily store the following information:

  • the viewer's public chat display name or username;
  • the chat platform from which the request originated;
  • the submitted YouTube URL or video ID;
  • the time the request was made;
  • the corresponding YouTube title, channel name, thumbnail URL, and duration; and
  • the request's position in the current DJ queue.

This information is used to operate the request queue, prevent duplicate or excessive requests, acknowledge requests in chat, and show the song and requester in the livestream overlay. DJ Gloggi does not intentionally collect viewers' email addresses, Google Account credentials, IP addresses, payment information, or private message history through the !dj request feature.

3. How Google user data is used

Google user data and OAuth authorization are used only to provide the user-facing DJ Gloggi functionality requested by the authenticated channel owner: validating YouTube video requests, obtaining the metadata necessary to identify and display those videos, and adding accepted videos to the channel owner's designated YouTube playlist.

DJ Gloggi does not use Google user data for advertising, targeted advertising, retargeting, credit decisions, data brokerage, profiling unrelated to the DJ feature, or training generalized artificial-intelligence or machine-learning models.

4. Sharing, transfer, and disclosure

DJ Gloggi does not sell Google user data or viewer request data. It does not provide Google user data to advertisers, data brokers, information resellers, or unrelated third parties.

Google OAuth credentials and authorized API requests are transmitted to Google only as necessary to authenticate with Google's OAuth service and use the YouTube Data API. YouTube videos and thumbnails displayed by the overlay are loaded from YouTube/Google services in the normal operation of the embedded player and artwork display.

DJ Gloggi does not operate a separate remote database or cloud backend for the queue. The active DJ state and credentials used by the Streamer.bot integration are maintained on the broadcaster's local computer.

5. Data storage and security

DJ Gloggi is designed as a locally operated Streamer.bot integration. OAuth client configuration, the refresh token, the current access token, the playlist ID, and the active DJ queue are stored locally in Streamer.bot's persistent data on the broadcaster's computer.

  • OAuth tokens are sent only to Google's OAuth and YouTube API endpoints when needed for authentication and API operations.
  • Communication with Google OAuth and YouTube API endpoints uses HTTPS.
  • The livestream overlay communicates with Streamer.bot through the broadcaster's local Streamer.bot connection rather than a DJ Gloggi-operated cloud database.
  • The DJ Gloggi website does not intentionally add advertising trackers or analytics scripts.

No method of local storage or electronic transmission can be guaranteed to be absolutely secure. The broadcaster is responsible for securing the computer, Streamer.bot installation, Google Cloud OAuth client credentials, and associated Google account.

6. Data retention and deletion

OAuth credentials

The OAuth refresh token is retained locally for as long as the broadcaster keeps DJ Gloggi connected to the Google account. Short-lived access tokens are replaced as needed. The broadcaster can delete the locally stored OAuth values from Streamer.bot and can revoke DJ Gloggi's Google access at any time through Google Account permissions.

DJ queue and viewer request information

DJ Gloggi's persistent queue contains only the currently playing request and requests waiting to play; it is not designed as a permanent viewer-request history. A completed track is removed from the active queue when playback advances. Remaining queue information persists locally across Streamer.bot restarts until those requests play, the queue is cleared, or the stored DJ state is removed by the broadcaster.

Deletion requests

A viewer who wants an active request associated with their username removed may contact the broadcaster through The Gustx Broadcast's published contact channel or during the livestream and ask for the request to be removed/cleared. The broadcaster can clear the active DJ state from Streamer.bot. Google account authorization can be revoked independently using Google's account-permissions page linked below.

7. User choices and revoking Google access

The broadcaster may stop using DJ Gloggi at any time. Google authorization can be revoked from Google Account → Third-party apps & services. After authorization is revoked, DJ Gloggi can no longer obtain valid OAuth access tokens for playlist operations unless the broadcaster authorizes the app again.

Viewers may choose not to use the !dj command. Not using the command does not prevent a viewer from otherwise participating in the livestream chat.

8. Google API Services User Data Policy / Limited Use

DJ Gloggi's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

9. YouTube and third-party services

DJ Gloggi uses YouTube and the YouTube Data API. Use of YouTube is also subject to the YouTube Terms of Service and Google Privacy Policy. Livestream chat platforms and Streamer.bot operate under their own terms and privacy practices.

10. Children's privacy

DJ Gloggi is not designed to knowingly collect personal information from children. The !dj feature processes only the limited public chat/request information described above. If information is believed to have been submitted by a child in a way that should be removed, the broadcaster may clear the applicable active request data.

11. Changes to this policy

This policy may be updated if DJ Gloggi's features or data practices change. The "Effective and last updated" date at the top of this page will be revised when material changes are published. DJ Gloggi's use of Google user data will remain limited to practices disclosed in the current published privacy policy.

12. Contact

Privacy questions or deletion requests may be directed to the operator of The Gustx Broadcast using the public contact information associated with DJ Gloggi.
