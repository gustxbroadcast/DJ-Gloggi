Privacy Policy

Last updated: REPLACE WITH TODAY'S DATE

DJ Gloggi ("the app") is a personal Twitch chat tool that adds viewer-requested YouTube videos to a playlist during live streams. This policy explains what data it touches.

Google account data

The app uses the YouTube Data API with the youtube scope, authorised once by the streamer's own Google account. That access is used for exactly one purpose: adding and removing videos in a playlist owned by that account.

The app does not read the streamer's watch history, subscriptions, email, contacts, or any other Google service. It never requests access to a viewer's Google account — viewers only post a link in chat.

Chat data

When a viewer requests a track, the app stores their Twitch display name alongside the video, so the stream overlay can show who asked for it. This is kept locally on the streamer's computer and is cleared regularly. No email addresses, IP addresses, or message history are collected.

Storage and sharing

  • Access tokens are stored locally on the streamer's own computer and are never transmitted anywhere except to Google.
  • No data is sold, shared with advertisers, or given to third parties.
  • No analytics or tracking is used on this website.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from Google Account permissions. Doing so immediately stops the app from touching the playlist.
